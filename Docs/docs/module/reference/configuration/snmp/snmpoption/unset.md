# Invoke-NSUnsetSNMPOption

## SYNOPSIS
Clears one or more NetScaler snmpoption resource properties.

## SYNTAX

```
Invoke-NSUnsetSNMPOption [-CustomTrap] [-PartitionNameInTrap] [-SeverityinfoinTrap] [-SNMPSet]
 [-SNMPTrapLogging] [-SNMPTrapLogginglevel] [[-Session] <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound]
 [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for SNMP option resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetSNMPOption -CustomTrap ENABLED -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetSNMPOption -CustomTrap ENABLED -WhatIf
```
