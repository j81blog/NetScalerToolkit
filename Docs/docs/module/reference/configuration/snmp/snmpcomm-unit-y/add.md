# Invoke-NSAddSNMPCommUnitY

## SYNOPSIS
Creates a NetScaler snmpcommunity resource.

## SYNTAX

```
Invoke-NSAddSNMPCommUnitY [-CommUnitYName] <String> -Permissions <String> [-Session <PSObject>]
 [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Configuration for community resource.

## EXAMPLES

### EXAMPLE 1

Invoke-NSAddSNMPCommUnitY -CommUnitYName 'example' -Permissions GET -PassThru
