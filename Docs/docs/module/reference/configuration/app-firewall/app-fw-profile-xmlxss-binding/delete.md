# Invoke-NSDeleteAppFwProfileXMLXssBinding

## SYNOPSIS
Removes a NetScaler appfwprofile_xmlxss_binding resource.

## SYNTAX

```
Invoke-NSDeleteAppFwProfileXMLXssBinding [-Name] <String> [-XMLXss <String>] [-AsScanLocationXMLXss <String>]
 [-RuleType <String>] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the xmlxss that can be bound to appfwprofile.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteAppFwProfileXMLXssBinding -Name 'example' -XMLXss 'example' -RuleType ALLOW -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetAppFwProfileXMLXssBinding -Name 'appfwprofile_xmlxss_binding_example' | Invoke-NSDeleteAppFwProfileXMLXssBinding -Confirm:$false
```

### -XMLXss
Exempt the specified URL from the XML cross-site scripting (XSS) check.
An XML cross-site scripting exemption (relaxation) consists of the following items: * URL.
URL to exempt, as a string or a PCRE-format regular expression.
* ISREGEX flag.
REGEX if URL is a regular expression, NOTREGEX if URL is a fixed string.
* Location.
ELEMENT if the attachment is located in an XML element, ATTRIBUTE if located in an XML attribute.
