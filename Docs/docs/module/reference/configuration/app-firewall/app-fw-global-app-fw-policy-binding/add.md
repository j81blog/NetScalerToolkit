# Invoke-NSAddAppFwGlobalAppFwPolicyBinding

## SYNOPSIS
Creates a NetScaler appfwglobal_appfwpolicy_binding resource.

## SYNTAX

```
Invoke-NSAddAppFwGlobalAppFwPolicyBinding [[-GotoPriorityExpression] <String>] [[-Invoke] <Boolean>]
 [[-LabelName] <String>] [[-LabelType] <String>] [-PolicyName] <String> [-Priority] <Int32> [[-State] <String>]
 [[-Type] <String>] [[-Session] <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the appfwpolicy that can be bound to appfwglobal.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddAppFwGlobalAppFwPolicyBinding -PolicyName 'example' -Priority 1 -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddAppFwGlobalAppFwPolicyBinding -PolicyName 'example' -Priority 1 -WhatIf
```
