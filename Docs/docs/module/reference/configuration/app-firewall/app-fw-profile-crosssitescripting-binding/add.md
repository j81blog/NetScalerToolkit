# Invoke-NSAddAppFwProfileCrosssitescriptingBinding

## SYNOPSIS
Creates a NetScaler appfwprofile_crosssitescripting_binding resource.

## SYNTAX

```
Invoke-NSAddAppFwProfileCrosssitescriptingBinding [-AsScanLocationXss <String>] [-AsValueExprXss <String>]
 [-AsValueTypeXss <String>] [-Comment <String>] [-Crosssitescripting <String>] [-FormActionURLXss <String>]
 [-Isautodeployed <String>] [-IsregexXss <String>] [-IsvalueregexXss <String>] [-Name] <String>
 [-Resourceid <String>] [-RuleType <String>] [-State <String>] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the crosssitescripting that can be bound to appfwprofile.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddAppFwProfileCrosssitescriptingBinding -Name 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddAppFwProfileCrosssitescriptingBinding -Name 'example' -WhatIf
```
