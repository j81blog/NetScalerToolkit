# Invoke-NSUnsetAppFwConfidField

## SYNOPSIS
Clears one or more NetScaler appfwconfidfield resource properties.

## SYNTAX

```
Invoke-NSUnsetAppFwConfidField [-FieldName] <String> [-Comment] [-Isregex] [-State] [-URL]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for configured confidential form fields resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetAppFwConfidField -FieldName 'example' -Comment 'Updated by automation' -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetAppFwConfidField -FieldName 'example' -Comment 'Updated by automation' -WhatIf
```
