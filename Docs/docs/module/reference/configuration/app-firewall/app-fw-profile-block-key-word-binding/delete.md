# Invoke-NSDeleteAppFwProfileBlockKeyWordBinding

## SYNOPSIS
Removes a NetScaler appfwprofile_blockkeyword_binding resource.

## SYNTAX

```
Invoke-NSDeleteAppFwProfileBlockKeyWordBinding [-Name] <String> [-BlockKeyWord <String>] [-FieldName <String>]
 [-AsBlockKeyWordFormURL <String>] [-RuleType <String>] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the blockkeyword that can be bound to appfwprofile.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteAppFwProfileBlockKeyWordBinding -Name 'example' -BlockKeyWord 'example' -FieldName 'example' -RuleType ALLOW -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetAppFwProfileBlockKeyWordBinding -Name 'appfwprofile_blockkeyword_binding_example' | Invoke-NSDeleteAppFwProfileBlockKeyWordBinding -Confirm:$false
```
