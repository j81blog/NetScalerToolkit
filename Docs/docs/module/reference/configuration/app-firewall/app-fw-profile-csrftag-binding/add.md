# Invoke-NSAddAppFwProfileCsrftagBinding

## SYNOPSIS
Creates a NetScaler appfwprofile_csrftag_binding resource.

## SYNTAX

```
Invoke-NSAddAppFwProfileCsrftagBinding [-Comment <String>] [-CsrfFormActionURL <String>] [-Csrftag <String>]
 [-Isautodeployed <String>] [-Name] <String> [-Resourceid <String>] [-RuleType <String>] [-State <String>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the csrftag that can be bound to appfwprofile.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddAppFwProfileCsrftagBinding -Name 'example' -PassThru
```
