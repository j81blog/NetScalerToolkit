# Invoke-NSDeleteAppFwPolicyLabelAppFwPolicyBinding

## SYNOPSIS
Removes a NetScaler appfwpolicylabel_appfwpolicy_binding resource.

## SYNTAX

```
Invoke-NSDeleteAppFwPolicyLabelAppFwPolicyBinding [-LabelName] <String> -PolicyName <String> -Priority <Int32>
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the appfwpolicy that can be bound to appfwpolicylabel.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteAppFwPolicyLabelAppFwPolicyBinding -LabelName 'example' -PolicyName 'example' -Priority 1 -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetAppFwPolicyLabelAppFwPolicyBinding -LabelName 'appfwpolicylabel_appfwpolicy_binding_example' | Invoke-NSDeleteAppFwPolicyLabelAppFwPolicyBinding -Confirm:$false
```
