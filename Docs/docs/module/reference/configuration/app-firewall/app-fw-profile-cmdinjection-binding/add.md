# Invoke-NSAddAppFwProfileCmdinjectionBinding

## SYNOPSIS
Creates a NetScaler appfwprofile_cmdinjection_binding resource.

## SYNTAX

```
Invoke-NSAddAppFwProfileCmdinjectionBinding [-AsScanLocationCmd <String>] [-AsValueExprCmd <String>]
 [-AsValueTypeCmd <String>] [-Cmdinjection <String>] [-Comment <String>] [-FormActionURLCmd <String>]
 [-Isautodeployed <String>] [-IsregexCmd <String>] [-IsvalueregexCmd <String>] [-Name] <String>
 [-Resourceid <String>] [-RuleType <String>] [-State <String>] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the cmdinjection that can be bound to appfwprofile.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddAppFwProfileCmdinjectionBinding -Name 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddAppFwProfileCmdinjectionBinding -Name 'example' -WhatIf
```
