# Invoke-NSAddAAAGroupAuthorizationPolicyBinding

## SYNOPSIS
Creates a NetScaler aaagroup_authorizationpolicy_binding resource.

## SYNTAX

```
Invoke-NSAddAAAGroupAuthorizationPolicyBinding [-GotoPriorityExpression <String>] [-GroupName] <String>
 [-Policy <String>] [-Priority <Int32>] [-Type <String>] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the authorizationpolicy that can be bound to aaagroup.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddAAAGroupAuthorizationPolicyBinding -GroupName 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddAAAGroupAuthorizationPolicyBinding -GroupName 'example' -WhatIf
```
