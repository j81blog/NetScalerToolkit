# Invoke-NSAddServicePathServiceFunctionBinding

## SYNOPSIS
Creates a NetScaler nsservicepath_nsservicefunction_binding resource.

## SYNTAX

```
Invoke-NSAddServicePathServiceFunctionBinding -Index <Int32> -ServiceFunction <String>
 [-ServicePathName] <String> [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the nsservicefunction that can be bound to nsservicepath.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddServicePathServiceFunctionBinding -ServicePathName 'example' -Index 1 -ServiceFunction 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddServicePathServiceFunctionBinding -ServicePathName 'example' -Index 1 -ServiceFunction 'example' -WhatIf
```
