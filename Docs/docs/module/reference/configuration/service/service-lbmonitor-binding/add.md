# Invoke-NSAddServiceLBMonitorBinding

## SYNOPSIS
Creates a NetScaler service_lbmonitor_binding resource.

## SYNTAX

```
Invoke-NSAddServiceLBMonitorBinding [-MonItorName <String>] [-MonState <String>] [-Name] <String>
 [-Passive <Boolean>] [-Weight <Int32>] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound]
 [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the lbmonitor that can be bound to service.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddServiceLBMonitorBinding -Name 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddServiceLBMonitorBinding -Name 'example' -WhatIf
```
