# Invoke-NSUnsetNAT64Param

## SYNOPSIS
Clears one or more NetScaler nat64param resource properties.

## SYNTAX

```
Invoke-NSUnsetNAT64Param [-TrafficDomain] <Int32> [-Nat64fragHeader] [-Nat64ignoretos] [-Nat64v6mtu]
 [-Nat64zerochecksum] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for NAT64 parameter resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetNAT64Param -TrafficDomain 1 -Nat64fragHeader ENABLED -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetNAT64Param -TrafficDomain 1 -Nat64fragHeader ENABLED -WhatIf
```
