# Invoke-NSAddNAT64

## SYNOPSIS
Creates a NetScaler nat64 resource.

## SYNTAX

```
Invoke-NSAddNAT64 -Acl6Name <String> [-Name] <String> [-NetProfile <String>] [-Session <PSObject>]
 [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Configuration for nat64 config resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddNAT64 -Name 'example' -Acl6Name 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddNAT64 -Name 'example' -Acl6Name 'example' -WhatIf
```

## PARAMETERS

### -Acl6Name
Name of any configured ACL6 whose action is ALLOW.
