# Invoke-NSDeleteTrafficDomainVlanBinding

## SYNOPSIS
Removes a NetScaler nstrafficdomain_vlan_binding resource.

## SYNTAX

```
Invoke-NSDeleteTrafficDomainVlanBinding [-TrafficDomain] <Int32> [-Vlan <Int32>] [-Session <PSObject>]
 [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the vlan that can be bound to nstrafficdomain.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteTrafficDomainVlanBinding -TrafficDomain 1 -Vlan 1 -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetTrafficDomainVlanBinding -TrafficDomain 'nstrafficdomain_vlan_binding_example' | Invoke-NSDeleteTrafficDomainVlanBinding -Confirm:$false
```
