# Invoke-NSUnsetNsratecontrol

## SYNOPSIS
Clears one or more NetScaler nsratecontrol resource properties.

## SYNTAX

```
Invoke-NSUnsetNsratecontrol [-ICMPThreshold] [-TCPRstThreshold] [-TCPThreshold] [-UDPThreshold]
 [[-Session] <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for rate control resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetNsratecontrol -ICMPThreshold  -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetNsratecontrol -ICMPThreshold  -WhatIf
```
