# Invoke-NSUnsetNsdhcpparams

## SYNOPSIS
Clears one or more NetScaler nsdhcpparams resource properties.

## SYNTAX

```
Invoke-NSUnsetNsdhcpparams [-DhcpClient] [-Saveroute] [[-Session] <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for DHCP parameters resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetNsdhcpparams -DhcpClient ON -PassThru
```

### EXAMPLE 2
