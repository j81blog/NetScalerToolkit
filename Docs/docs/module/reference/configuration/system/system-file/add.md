# Invoke-NSAddSystemFile

## SYNOPSIS
Uploads a NetScaler system file.

## SYNTAX

```
Invoke-NSAddSystemFile -FileContent <String> [-FileEncoding <String>] -FileLocation <String>
 [-FileName] <String> [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for file resource.

Invoke-NSAddSystemFile -FileName 'example' -FileContent 'example' -FileLocation 'example' -PassThru
