# Invoke-NSGetVridInterfaceBinding

## SYNOPSIS
Gets NetScaler vrid_interface_binding configuration.

## PARAMETERS

### -Id
Integer that uniquely identifies the VMAC address.
The generic VMAC address is in the form of 00:00:5e:00:01:\<VRID\>.
For example, if you add a VRID with a value of 60 and bind it to an interface, the resulting VMAC address is 00:00:5e:00:01:3c, where 3c is the hexadecimal representation of 60.
Minimum value = 1 Maximum value = 255
