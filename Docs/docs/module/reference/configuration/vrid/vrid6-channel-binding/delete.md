# Invoke-NSDeleteVrid6ChannelBinding

## SYNOPSIS
Removes a NetScaler vrid6_channel_binding resource.

## SYNTAX

```
Invoke-NSDeleteVrid6ChannelBinding [-Id] <Int32> [-Ifnum <String>] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the channel that can be bound to vrid6.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteVrid6ChannelBinding -Id 1 -Ifnum 'example' -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetVrid6ChannelBinding -Id 'vrid6_channel_binding_example' | Invoke-NSDeleteVrid6ChannelBinding -Confirm:$false
```
