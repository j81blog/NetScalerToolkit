# Invoke-NSUpdatePolicyPATSet

## SYNOPSIS
Updates a NetScaler policypatset resource.

## SYNTAX

```
Invoke-NSUpdatePolicyPATSet [-Dynamic <String>] [-Name] <String> [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

## PARAMETERS

### -Dynamic
This is used to populate internal patset information so that the patset can also be used dynamically in an expression.
Here dynamically means the patset name can also be derived using an expression.
For example for a given patset name "allow_test" it can be used dynamically as http.req.url.contains_any("allow_" + http.req.url.path.get(1)).
This cannot be used with default patsets.
Default value: NO Possible values = YES, NO
