# Invoke-NSAddLSNLogProfile

## SYNOPSIS
Creates a NetScaler lsnlogprofile resource.

## SYNTAX

```
Invoke-NSAddLSNLogProfile [-AnalyticsProfile <String>] [-Logcompact <String>] [-Logipfix <String>]
 [-LogProfileName] <String> [-Logsessdeletion <String>] [-Logsubscrinfo <String>] [-Session <PSObject>]
 [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Configuration for LSN logging Profile resource.

## EXAMPLES
