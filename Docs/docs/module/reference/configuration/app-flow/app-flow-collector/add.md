# Invoke-NSAddAppFlowCollector

## SYNOPSIS
Creates a NetScaler appflowcollector resource.

## SYNTAX

```
Invoke-NSAddAppFlowCollector -Ipaddress <String> [-Name] <String> [-NetProfile <String>] [-Port <Int32>]
 [-TransPort <String>] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for AppFlow collector resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddAppFlowCollector -Name 'example' -Ipaddress 'example' -Port 80 -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddAppFlowCollector -Name 'example' -Ipaddress 'example' -Port 80 -WhatIf
```
