# Invoke-NSDeleteSimpleACL6

## SYNOPSIS
Removes a NetScaler nssimpleacl6 resource.

## SYNTAX

```
Invoke-NSDeleteSimpleACL6 [-AclName] <String> [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound]
 [-ThrowOnWarning] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for simple ACL6 resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteSimpleACL6 -AclName 'example' -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetSimpleACL6 -AclName 'nssimpleacl6_example' | Invoke-NSDeleteSimpleACL6 -Confirm:$false
```

Cannot be changed after the simple ACL6 rule is created.
Minimum length = 1
