# Invoke-NSUnsetDNSNameServer

## SYNOPSIS
Clears one or more NetScaler dnsnameserver resource properties.

## SYNTAX

```
Invoke-NSUnsetDNSNameServer [-Ip] <String> [-DNSProfileName] [-Type] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for name server resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetDNSNameServer -Ip 'example' -DNSProfileName  -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetDNSNameServer -Ip 'example' -DNSProfileName  -WhatIf
```
