# Invoke-NSAddINAT

## SYNOPSIS
Creates a NetScaler inat resource.

## SYNTAX

```
Invoke-NSAddINAT [-ConnFailover <String>] [-Ftp <String>] [-Mode <String>] [-Name] <String> -Privateip <String>
 [-ProxyIp <String>] -Publicip <String> [-TCPProxy <String>] [-TrafficDomain <Int32>] [-Tftp <String>]
 [-UseProxyPort <String>] [-USIP <String>] [-Usnip <String>] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for inbound nat resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddINAT -Name 'example' -Privateip 'example' -Publicip 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddINAT -Name 'example' -Privateip 'example' -Publicip 'example' -WhatIf
```
