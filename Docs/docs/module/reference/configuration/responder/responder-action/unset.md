# Invoke-NSUnsetResponderAction

## SYNOPSIS
Clears one or more NetScaler responderaction resource properties.

## SYNTAX

```
Invoke-NSUnsetResponderAction [-Name] <String> [-Comment] [-HeaderS] [-Reasonphrase] [-ResponseStatuscode]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for responder action resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetResponderAction -Name 'example' -Comment 'Updated by automation' -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetResponderAction -Name 'example' -Comment 'Updated by automation' -WhatIf
```

The following requirement applies only to the Citrix ADC CLI: If the name includes one or more spaces, enclose the name in double or single quotation marks (for example, "my responder action" or 'my responder action').
