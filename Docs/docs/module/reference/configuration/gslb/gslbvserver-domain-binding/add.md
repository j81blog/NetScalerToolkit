# Invoke-NSAddGSLBVServerDomainBinding

## SYNOPSIS
Creates a NetScaler gslbvserver_domain_binding resource.

## SYNTAX

```
Invoke-NSAddGSLBVServerDomainBinding [-BackupIp <String>] [-CookieDomain <String>] [-CookieTimeout <Int32>]
 [-DomainName <String>] [-Name] <String> [-Order <Int32>] [-Sitedomainttl <Int32>] [-Ttl <Int32>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the domain that can be bound to gslbvserver.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddGSLBVServerDomainBinding -Name 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddGSLBVServerDomainBinding -Name 'example' -WhatIf
```
