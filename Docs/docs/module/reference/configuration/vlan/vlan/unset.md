# Invoke-NSUnsetVlan

## SYNOPSIS
Clears one or more NetScaler vlan resource properties.

## SYNTAX

```
Invoke-NSUnsetVlan [-Id] <Int32> [-AliasName] [-Dynamicrouting] [-IPv6Dynamicrouting] [-Mtu] [-Sharing]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for "VLAN" resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetVlan -Id 1 -AliasName  -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetVlan -Id 1 -AliasName  -WhatIf
```
