# Invoke-NSUpdateSSLCipher

## SYNOPSIS
Updates a NetScaler sslcipher resource.

## SYNTAX

```
Invoke-NSUpdateSSLCipher [-CipherGroupName] <String> [-CipherName <String>] [-CipherPriority <Int32>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for cipher resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUpdateSSLCipher -CipherGroupName 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSUpdateSSLCipher -CipherGroupName 'example' -WhatIf
```

## PARAMETERS

### -CipherGroupName
Name for the user-defined cipher group.
Must begin with an ASCII alphanumeric or underscore (_) character, and must contain only ASCII alphanumeric, underscore, hash (#), period (.), space, colon (:), at (@), equals (=), and hyphen (-) characters.
Cannot be changed after the cipher group is created.
The following requirement applies only to the Citrix ADC CLI: If the name includes one or more spaces, enclose the name in double or single quotation marks (for example, "my ciphergroup" or 'my ciphergroup').
Minimum length = 1
