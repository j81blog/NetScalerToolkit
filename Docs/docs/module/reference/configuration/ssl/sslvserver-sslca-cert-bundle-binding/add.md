# Invoke-NSAddSSLVServerSSLCaCertBundleBinding

## SYNOPSIS
Creates a NetScaler sslvserver_sslcacertbundle_binding resource.

## SYNTAX

```
Invoke-NSAddSSLVServerSSLCaCertBundleBinding [-CaCertBundleName <String>] [-SkipcaCertBundle <Boolean>]
 [-VServerName] <String> [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the sslcacertbundle that can be bound to sslvserver.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddSSLVServerSSLCaCertBundleBinding -VServerName 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddSSLVServerSSLCaCertBundleBinding -VServerName 'example' -WhatIf
```
