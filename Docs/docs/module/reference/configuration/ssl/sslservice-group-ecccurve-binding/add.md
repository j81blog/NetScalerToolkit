# Invoke-NSAddSSLServiceGroupEcccurveBinding

## SYNOPSIS
Creates a NetScaler sslservicegroup_ecccurve_binding resource.

## SYNTAX

```
Invoke-NSAddSSLServiceGroupEcccurveBinding [-EcccurveName <String>] [-ServiceGroupName] <String>
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the ecccurve that can be bound to sslservicegroup.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddSSLServiceGroupEcccurveBinding -ServiceGroupName 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddSSLServiceGroupEcccurveBinding -ServiceGroupName 'example' -WhatIf
```
