# Invoke-NSAddSSLDtlsProfile

## SYNOPSIS

## SYNTAX

```

 [-MaxBadmacignorecount <Int32>] [-MaxHoldqlen <Int32>] [-MaxPacketsize <Int32>] [-MaxRecordSize <Int32>]
 [-MaxRetrytime <Int32>] [-Name] <String> [-Pmtudiscovery <String>] [-TerMinAtesession <String>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
