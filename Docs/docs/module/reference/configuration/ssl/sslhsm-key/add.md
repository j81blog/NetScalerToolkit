# Invoke-NSAddSSLHsmKey

## SYNOPSIS

## SYNTAX

```

 [-Password <String>] [-Serialnum <String>] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound]
 [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```
