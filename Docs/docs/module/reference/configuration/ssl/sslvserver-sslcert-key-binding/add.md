# Invoke-NSAddSSLVServerSSLCertKeyBinding

## SYNOPSIS
Creates a NetScaler sslvserver_sslcertkey_binding resource.

## SYNTAX

```
Invoke-NSAddSSLVServerSSLCertKeyBinding [-Ca <Boolean>] [-CertKeyName <String>] [-Crlcheck <String>]
 [-OCSPCheck <String>] [-SkipcaName <Boolean>] [-SniCert <Boolean>] [-VServerName] <String>
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the sslcertkey that can be bound to sslvserver.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddSSLVServerSSLCertKeyBinding -VServerName 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddSSLVServerSSLCertKeyBinding -VServerName 'example' -WhatIf
```
