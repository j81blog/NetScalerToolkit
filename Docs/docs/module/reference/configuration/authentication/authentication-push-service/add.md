# Invoke-NSAddAuthenticationPushService

## SYNOPSIS
Creates a NetScaler authenticationpushservice resource.

## SYNTAX

 [-Name] <String> [-RefreshInterval <Int32>] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound]
