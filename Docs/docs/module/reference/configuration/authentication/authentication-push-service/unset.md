# Invoke-NSUnsetAuthenticationPushService

## SYNOPSIS
Clears one or more NetScaler authenticationpushservice resource properties.

## SYNTAX

```
Invoke-NSUnsetAuthenticationPushService [-Name] <String> [-RefreshInterval] [-Session <PSObject>]
 [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Configuration for Service details for sending push notifications resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetAuthenticationPushService -Name 'example' -RefreshInterval  -PassThru
```

### EXAMPLE 2

Invoke-NSUnsetAuthenticationPushService -Name 'example' -RefreshInterval  -WhatIf
