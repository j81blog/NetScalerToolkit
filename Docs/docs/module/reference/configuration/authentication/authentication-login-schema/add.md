## PARAMETERS

### -AuthenticationSchema
Name of the file for reading authentication schema to be sent for Login Page UI.
This file should contain xml definition of elements as per Citrix Forms Authentication Protocol to be able to render login form.
If administrator does not want to prompt users for additional credentials but continue with previously obtained credentials, then "noschema" can be given as argument.
Please note that this applies only to loginSchemas that are used with user-defined factors, and not the vserver factor.
