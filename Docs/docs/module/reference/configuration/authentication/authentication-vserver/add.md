# Invoke-NSAddAuthenticationVServer

## SYNOPSIS
Creates a NetScaler authenticationvserver resource.

## SYNTAX

```
Invoke-NSAddAuthenticationVServer [-AppFlowLog <String>] [-Authentication <String>]
 [-AuthenticationDomain <String>] [-CertKeyNameS <String>] [-Comment <String>] [-FailedLoginTimeout <Int32>]
 [-IPv46 <String>] [-MaxLoginAttempts <Int32>] [-Name] <String> [-Port <Int32>] [-Range <Int32>]
 [-Samesite <String>] -ServiceType <String> [-State <String>] [-TrafficDomain <Int32>] [-WASMModule <String>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for authentication virtual server resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddAuthenticationVServer -Name 'example' -ServiceType SSL -IPv46 '192.0.2.10' -Port 80 -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddAuthenticationVServer -Name 'example' -ServiceType SSL -IPv46 '192.0.2.10' -Port 80 -WhatIf
```
