# Invoke-NSAddAuthenticationVServerCachePolicyBinding

## SYNOPSIS
Creates a NetScaler authenticationvserver_cachepolicy_binding resource.

## SYNTAX

```
Invoke-NSAddAuthenticationVServerCachePolicyBinding [-Bindpoint <String>] [-GotoPriorityExpression <String>]
 [-GroupExtrAction <Boolean>] [-Name] <String> [-Nextfactor <String>] [-Policy <String>] [-Priority <Int32>]
 [-Secondary <Boolean>] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the cachepolicy that can be bound to authenticationvserver.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddAuthenticationVServerCachePolicyBinding -Name 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddAuthenticationVServerCachePolicyBinding -Name 'example' -WhatIf
```
