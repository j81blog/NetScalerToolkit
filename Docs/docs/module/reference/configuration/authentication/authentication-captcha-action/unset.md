# Invoke-NSUnsetAuthenticationCaptchaAction

## SYNOPSIS
Clears one or more NetScaler authenticationcaptchaaction resource properties.

## SYNTAX

```
Invoke-NSUnsetAuthenticationCaptchaAction [-Name] <String> [-DefaultAuthenticationGroup] [-ScoreThreshold]
 [-ServerURL] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for Captcha Action resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetAuthenticationCaptchaAction -Name 'example' -DefaultAuthenticationGroup  -PassThru
```

### EXAMPLE 2
