# Invoke-NSEnableLBMonitor

## SYNOPSIS
Enables a NetScaler lbmonitor resource.

## SYNTAX

```
Invoke-NSEnableLBMonitor [-MonItorName] <String> [-ServiceGroupName <String>] [-ServiceName <String>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for monitor resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSEnableLBMonitor -MonItorName 'lbmonitor_example' -PassThru
```
