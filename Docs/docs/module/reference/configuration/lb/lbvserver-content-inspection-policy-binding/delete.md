# Invoke-NSDeleteLBVServerContentInspectionPolicyBinding

## SYNOPSIS
Removes a NetScaler lbvserver_contentinspectionpolicy_binding resource.

## SYNTAX

```
Invoke-NSDeleteLBVServerContentInspectionPolicyBinding [-Name] <String> [-PolicyName <String>]
 [-Bindpoint <String>] [-Priority <Int32>] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound]
 [-ThrowOnWarning] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the contentinspectionpolicy that can be bound to lbvserver.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteLBVServerContentInspectionPolicyBinding -Name 'example' -PolicyName 'example' -Bindpoint REQUEST -Priority 1 -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetLBVServerContentInspectionPolicyBinding -Name 'lbvserver_contentinspectionpolicy_binding_example' | Invoke-NSDeleteLBVServerContentInspectionPolicyBinding -Confirm:$false
```
