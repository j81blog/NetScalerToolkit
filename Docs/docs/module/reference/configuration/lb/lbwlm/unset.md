# Invoke-NSUnsetLBWLM

## SYNOPSIS
Clears one or more NetScaler lbwlm resource properties.

## SYNTAX

```
Invoke-NSUnsetLBWLM [-WlmName] <String> [-KaTimeout] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for web log manager resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetLBWLM -WlmName 'example' -KaTimeout  -PassThru
```
