# Invoke-NSAddLBWLM

## SYNOPSIS
Creates a NetScaler lbwlm resource.

## SYNTAX

```
Invoke-NSAddLBWLM [-Ipaddress <String>] [-KaTimeout <Int32>] -Lbuid <String> [-Port <Int32>]
 [-WlmName] <String> [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for web log manager resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddLBWLM -WlmName 'example' -Lbuid 'example' -Port 80 -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddLBWLM -WlmName 'example' -Lbuid 'example' -Port 80 -WhatIf
```
