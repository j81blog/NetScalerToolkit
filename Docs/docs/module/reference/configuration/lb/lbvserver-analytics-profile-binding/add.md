# Invoke-NSAddLBVServerAnalyticsProfileBinding

## SYNOPSIS
Creates a NetScaler lbvserver_analyticsprofile_binding resource.

## SYNTAX

```
Invoke-NSAddLBVServerAnalyticsProfileBinding [-AnalyticsProfile <String>] [-Name] <String> [-Order <Int32>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the analyticsprofile that can be bound to lbvserver.

## EXAMPLES

### EXAMPLE 1
