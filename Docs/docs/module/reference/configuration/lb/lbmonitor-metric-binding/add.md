# Invoke-NSAddLBMonitorMetricBinding

## SYNOPSIS
Creates a NetScaler lbmonitor_metric_binding resource.

## SYNTAX

```
Invoke-NSAddLBMonitorMetricBinding [-Metric <String>] [-MetricThreshold <Int32>] [-Metricweight <Int32>]
 [-MonItorName] <String> [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the metric that can be bound to lbmonitor.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddLBMonitorMetricBinding -MonItorName 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddLBMonitorMetricBinding -MonItorName 'example' -WhatIf
```
