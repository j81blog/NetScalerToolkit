# Invoke-NSAddRnat6

## SYNOPSIS
Creates a NetScaler rnat6 resource.

## SYNTAX

```
Invoke-NSAddRnat6 [-Acl6Name <String>] [-Name] <String> [-Network <String>] [-OwnerGroup <String>]
 [-RedirectPort <Int32>] [-Srcippersistency <String>] [-TrafficDomain <Int32>] [-Session <PSObject>]
 [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Configuration for IPv6 RNAT configured route resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddRnat6 -Name 'example' -PassThru
```
