# Invoke-NSUpdateIPTunnel

## SYNOPSIS
Updates a NetScaler iptunnel resource.

## SYNTAX

```
Invoke-NSUpdateIPTunnel [-DestPort <Int32>] [-Name] <String> [-Tosinherit <String>] [-Vlantagging <String>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for ip Tunnel resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUpdateIPTunnel -Name 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSUpdateIPTunnel -Name 'example' -WhatIf
```
