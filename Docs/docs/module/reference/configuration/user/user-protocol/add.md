# Invoke-NSAddUserProtocol

## SYNOPSIS
Creates a NetScaler userprotocol resource.

## SYNTAX

```
Invoke-NSAddUserProtocol [-Comment <String>] [-Extension <String>] [-Name] <String> -TransPort <String>
 [-WASMModule <String>] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for user protocol resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddUserProtocol -Name 'example' -TransPort TCP -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddUserProtocol -Name 'example' -TransPort TCP -WhatIf
```
