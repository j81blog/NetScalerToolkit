# Invoke-NSUnsetVPNTrafficAction

## SYNOPSIS
Clears one or more NetScaler vpntrafficaction resource properties.

## SYNTAX

```
Invoke-NSUnsetVPNTrafficAction [-Name] <String> [-KCDAccount] [-Passwdexpression] [-Proxy] [-UserExpression]
 [-Wanscaler] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for VPN traffic action resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetVPNTrafficAction -Name 'example' -KCDAccount  -PassThru
```

### EXAMPLE 2
