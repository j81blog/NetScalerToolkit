# Invoke-NSAddVPNNextHopServer

## SYNOPSIS

## SYNTAX

 -NexthopPort <Int32> [-ResaddressType <String>] [-Secure <String>] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
