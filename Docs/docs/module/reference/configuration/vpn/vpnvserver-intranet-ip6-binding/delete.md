# Invoke-NSDeleteVPNVServerIntranetIp6Binding

## SYNOPSIS
Removes a NetScaler vpnvserver_intranetip6_binding resource.

## SYNTAX

```
Invoke-NSDeleteVPNVServerIntranetIp6Binding [-Name] <String> [-IntranetIp6 <String>] [-Numaddr <Int32>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the intranetip6 that can be bound to vpnvserver.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteVPNVServerIntranetIp6Binding -Name 'example' -IntranetIp6 'example' -Numaddr 1 -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetVPNVServerIntranetIp6Binding -Name 'vpnvserver_intranetip6_binding_example' | Invoke-NSDeleteVPNVServerIntranetIp6Binding -Confirm:$false
```
