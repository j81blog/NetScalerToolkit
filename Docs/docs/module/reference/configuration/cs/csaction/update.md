# Invoke-NSUpdateCSAction

## SYNOPSIS
Updates a NetScaler csaction resource.

## SYNTAX

```
Invoke-NSUpdateCSAction [-Comment <String>] [-Name] <String> [-TargetlbVServer <String>]
 [-TargetVServer <String>] [-TargetVServerExpr <String>] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for Content Switching action resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUpdateCSAction -Name 'example' -Comment 'Updated by automation' -PassThru
```

### EXAMPLE 2
