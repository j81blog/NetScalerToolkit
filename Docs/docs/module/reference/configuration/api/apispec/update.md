# Invoke-NSUpdateAPISpec

## SYNOPSIS
Invokes the change operation for a NetScaler apispec resource.

## SYNTAX

```
Invoke-NSUpdateAPISpec -File <String> [-Name] <String> [-Skipvalidation <String>] [-Type <String>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Configuration for API specification resource.

## EXAMPLES

### EXAMPLE 1

Invoke-NSUpdateAPISpec -Name 'example' -File 'example'

## PARAMETERS

### -File
Name of and, optionally, path to the api spec file.
The spec file should be present on the appliance's hard-disk drive or solid-state drive.
Storing a spec file in any location other than the default might cause inconsistency in a high availability setup.
/nsconfig/apispec/ is the default path.
Minimum length = 1

Cannot be changed after the spec is created.
The following requirement applies only to the Citrix ADC CLI: If the name includes one or more spaces, enclose the name in double or single quotation marks (for example, "my spec" or 'my spec').
