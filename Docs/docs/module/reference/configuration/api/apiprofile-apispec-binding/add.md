# Invoke-NSAddAPIProfileAPISpecBinding

## SYNOPSIS
Creates a NetScaler apiprofile_apispec_binding resource.

## SYNTAX

```
Invoke-NSAddAPIProfileAPISpecBinding -APISpec <String> [-Name] <String> [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the apispec that can be bound to apiprofile.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddAPIProfileAPISpecBinding -Name 'example' -APISpec 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddAPIProfileAPISpecBinding -Name 'example' -APISpec 'example' -WhatIf
```
