# Invoke-NSUnsetAPIProfile

## SYNOPSIS
Clears one or more NetScaler apiprofile resource properties.

## SYNTAX

```
Invoke-NSUnsetAPIProfile [-Name] <String> [-APIVisibility] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for API profile resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetAPIProfile -Name 'example' -APIVisibility ENABLED -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetAPIProfile -Name 'example' -APIVisibility ENABLED -WhatIf
```
