# Invoke-NSUnsetProtocolHTTPBand

## SYNOPSIS
Clears one or more NetScaler protocolhttpband resource properties.

## SYNTAX

```
Invoke-NSUnsetProtocolHTTPBand [-Reqbandsize] [-ResponseBandsize] [[-Session] <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for HTTP request/response band resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetProtocolHTTPBand -Reqbandsize  -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetProtocolHTTPBand -Reqbandsize  -WhatIf
```
