# Invoke-NSUnsetVxlan

## SYNOPSIS
Clears one or more NetScaler vxlan resource properties.

## SYNTAX

```
Invoke-NSUnsetVxlan [-Id] <Int32> [-Dynamicrouting] [-Innervlantagging] [-IPv6Dynamicrouting] [-Port] [-Vlan]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for "VXLAN" resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetVxlan -Id 1 -Dynamicrouting ENABLED -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetVxlan -Id 1 -Dynamicrouting ENABLED -WhatIf
```
