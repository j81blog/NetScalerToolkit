# Invoke-NSAddLocationFile6

## SYNOPSIS
Creates a NetScaler locationfile6 resource.

## SYNTAX

```
Invoke-NSAddLocationFile6 [[-FormAt] <String>] [-LocationFile] <String> [[-Session] <PSObject>]
 [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Configuration for location file6 resource.
