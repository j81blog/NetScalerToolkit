# Invoke-NSUnsetSmppparam

## SYNOPSIS
Clears one or more NetScaler smppparam resource properties.

## SYNTAX

```
Invoke-NSUnsetSmppparam [-Addrnpi] [-Addrrange] [-Addrton] [-ClientMode] [-Msgqueue] [-Msgqueuesize]
 [[-Session] <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for SMPP configuration parameters resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetSmppparam -Addrnpi  -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetSmppparam -Addrnpi  -WhatIf
```
