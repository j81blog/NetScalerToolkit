# Invoke-NSDeleteSmppUser

## SYNOPSIS
Removes a NetScaler smppuser resource.

## SYNTAX

```
Invoke-NSDeleteSmppUser [-UserName] <String> [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound]
 [-ThrowOnWarning] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for SMPP user resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteSmppUser -UserName 'example' -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetSmppUser -UserName 'smppuser_example' | Invoke-NSDeleteSmppUser -Confirm:$false
```
