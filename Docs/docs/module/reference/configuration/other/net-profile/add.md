# Invoke-NSAddNetProfile

## SYNOPSIS
Creates a NetScaler netprofile resource.

## SYNTAX

```
Invoke-NSAddNetProfile [-BadipActionThreshold <Int32>] [-Mbf <String>] [-Name] <String> [-Overridelsn <String>]
 [-ProxyProtocol <String>] [-ProxyProtocolAftertlshandshake <String>] [-ProxyProtocolTxversion <String>]
 [-Srcip <String>] [-Srcippersistency <String>] [-TrafficDomain <Int32>] [-Session <PSObject>]
 [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Configuration for Network profile resource.

```
Invoke-NSAddNetProfile -Name 'example' -PassThru
```
