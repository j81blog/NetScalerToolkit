# Invoke-NSUnsetExtension

## SYNOPSIS
Clears one or more NetScaler nsextension resource properties.

## SYNTAX

```
Invoke-NSUnsetExtension [-Name] <String> [-Comment] [-Trace] [-Tracefunctions] [-Tracevariables]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for Extension resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetExtension -Name 'example' -Comment 'Updated by automation' -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetExtension -Name 'example' -Comment 'Updated by automation' -WhatIf
```
