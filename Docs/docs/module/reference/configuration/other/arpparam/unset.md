# Invoke-NSUnsetArpparam

## SYNOPSIS
Clears one or more NetScaler arpparam resource properties.

## SYNTAX

```
Invoke-NSUnsetArpparam [-Spoofvalidation] [-Timeout] [[-Session] <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for Global arp parameters resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetArpparam -Spoofvalidation ENABLED -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetArpparam -Spoofvalidation ENABLED -WhatIf
```

### -Timeout
Time-out value (aging time) for the dynamically learned ARP entries, in seconds.
The new value applies only to ARP entries that are dynamically learned after the new value is set.
Previously existing ARP entries expire after the previously configured aging time.
