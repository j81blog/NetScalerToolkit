# Invoke-NSUnsetL3param

## SYNOPSIS
Clears one or more NetScaler l3param resource properties.

## SYNTAX

```
Invoke-NSUnsetL3param [-Acllogtime] [-AllowclasseIPv4] [-Dropdfflag] [-Dropipfragments] [-Dynamicrouting]
 [-Externalloopback] [-ForwardICMPFragments] [-ICMPGenrateThreshold] [-Implicitaclallow] [-Implicitpbr]
 [-IPv6Dynamicrouting] [-Miproundrobin] [-Overridernat] [-Srcnat] [-TnlpmtuwoConn] [-USIPServerStraypkt]
 [[-Session] <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for Layer 3 related parameter resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetL3param -Acllogtime  -PassThru
```
