# Invoke-NSAddNetBridgeVlanBinding

## SYNOPSIS
Creates a NetScaler netbridge_vlan_binding resource.

## SYNTAX

```
Invoke-NSAddNetBridgeVlanBinding [-Name] <String> [-Vlan <Int32>] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the vlan that can be bound to netbridge.

### EXAMPLE 1
