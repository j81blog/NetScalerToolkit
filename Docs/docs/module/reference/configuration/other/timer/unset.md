# Invoke-NSUnsetTimer

## SYNOPSIS
Clears one or more NetScaler nstimer resource properties.

## SYNTAX

```
Invoke-NSUnsetTimer [-Name] <String> [-Comment] [-Interval] [-Unit] [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for Timer resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetTimer -Name 'example' -Comment 'Updated by automation' -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetTimer -Name 'example' -Comment 'Updated by automation' -WhatIf
```
