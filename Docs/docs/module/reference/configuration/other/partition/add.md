# Invoke-NSAddPartition

## SYNOPSIS
Creates a NetScaler partition.

## SYNTAX

```
Invoke-NSAddPartition [-MaxBandwidth <Int32>] [-MaxConn <Int32>] [-MaxMemlimit <Int32>] [-MinBandwidth <Int32>]
 [-PartitionMac <String>] [-PartitionName] <String> [-Session <PSObject>] [-IgnoreNotFound]
 [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for admin partition resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddPartition -PartitionName 'example' -PassThru
```

### EXAMPLE 2
```
Invoke-NSAddPartition -PartitionName 'example' -WhatIf
```
