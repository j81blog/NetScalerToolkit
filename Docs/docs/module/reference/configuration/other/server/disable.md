# Invoke-NSDisableServer

## SYNOPSIS
Disables a NetScaler server.

## SYNTAX

```
Invoke-NSDisableServer [-Name] <String> [-Delay <Int32>] [-Graceful <String>] [-Session <PSObject>]
 [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Configuration for server resource.

## EXAMPLES
