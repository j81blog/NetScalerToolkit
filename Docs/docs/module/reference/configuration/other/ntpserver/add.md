# Invoke-NSAddNTPServer

## SYNOPSIS
Creates a NetScaler ntpserver resource.

## SYNTAX

 [[-ServerIp] <String>] [-ServerName <String>] [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound]
