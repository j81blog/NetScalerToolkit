# Invoke-NSAddNetProfileSrcPortSetBinding

## SYNOPSIS
Creates a NetScaler netprofile_srcportset_binding resource.

## SYNTAX

```
Invoke-NSAddNetProfileSrcPortSetBinding [-Name] <String> [-SrcPortRange <String>] [-Session <PSObject>]
 [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the srcportset that can be bound to netprofile.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSAddNetProfileSrcPortSetBinding -Name 'example' -PassThru
```
