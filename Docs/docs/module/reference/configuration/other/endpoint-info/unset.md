# Invoke-NSUnsetEndpointInfo

## SYNOPSIS
Clears one or more NetScaler endpointinfo resource properties.

## SYNTAX

```
Invoke-NSUnsetEndpointInfo [-EndpointKind] <String> [-EndpointLabelSJson] [-EndpointmetaData] [-EndpointName]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-PassThru] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for Information resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetEndpointInfo -EndpointKind IP -EndpointLabelSJson  -PassThru
```

### EXAMPLE 2
```
Invoke-NSUnsetEndpointInfo -EndpointKind IP -EndpointLabelSJson  -WhatIf
```
