# Invoke-NSUnsetIp6tunnelparam

## SYNOPSIS
Clears one or more NetScaler ip6tunnelparam resource properties.

## SYNTAX

```
Invoke-NSUnsetIp6tunnelparam [-Dropfrag] [-DropfragcpuThreshold] [-Srcip] [-Srciproundrobin]
 [-UseClientsOurceIPv6] [[-Session] <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Configuration for ip6 tunnel parameter resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSUnsetIp6tunnelparam -Dropfrag YES -PassThru
```

### EXAMPLE 2
