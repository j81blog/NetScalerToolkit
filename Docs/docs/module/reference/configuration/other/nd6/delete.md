# Invoke-NSDeleteND6

## SYNOPSIS
Removes a NetScaler nd6 resource.

## SYNTAX

```
Invoke-NSDeleteND6 [-Neighbor] <String> [-Vlan <Int32>] [-Vxlan <Int32>] [-TrafficDomain <Int32>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Configuration for nd6 resource.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteND6 -Neighbor 'example' -Vlan 1 -Vxlan 1 -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetND6 -Neighbor 'nd6_example' | Invoke-NSDeleteND6 -Confirm:$false
```
