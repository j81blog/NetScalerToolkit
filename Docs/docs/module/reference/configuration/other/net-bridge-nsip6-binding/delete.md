# Invoke-NSDeleteNetBridgeNSIP6Binding

## SYNOPSIS
Removes a NetScaler netbridge_nsip6_binding resource.

## SYNTAX

```
Invoke-NSDeleteNetBridgeNSIP6Binding [-Name] <String> [-Ipaddress <String>] [-NetMask <String>]
 [-Session <PSObject>] [-IgnoreNotFound] [-ReturnNullOnNotFound] [-ThrowOnWarning] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Binding object showing the nsip6 that can be bound to netbridge.

## EXAMPLES

### EXAMPLE 1
```
Invoke-NSDeleteNetBridgeNSIP6Binding -Name 'example' -Ipaddress 'example' -NetMask '255.255.255.255' -Confirm:$false
```

### EXAMPLE 2
```
Invoke-NSGetNetBridgeNSIP6Binding -Name 'netbridge_nsip6_binding_example' | Invoke-NSDeleteNetBridgeNSIP6Binding -Confirm:$false
```
