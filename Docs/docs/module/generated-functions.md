# Generated Functions

Configuration and Statistics commands are generated from NetScaler resource metadata. They are exposed through the module manifests and documented in the generated reference.

The generated reference is organized first by module area:

- Common
- Configuration
- Statistics

Configuration and Statistics pages are then grouped by resource and action.

## Common Actions

| Action | Meaning |
| --- | --- |
| `Get` | read resource or binding state |
| `Add` | create resource or add binding |
| `Update` | update resource |
| `Delete` | remove resource or binding |
| `Unset` | clear selected resource properties |
| `Enable` / `Disable` | invoke enable or disable action |
| `Rename` | rename resource |
| `Save` | save or persist NetScaler state |

See [Reference](reference/index.md).
